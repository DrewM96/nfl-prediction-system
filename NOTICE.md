# Data Notice

This software retrieves NFL data through the nflverse ecosystem and `nflreadpy`.

- nflverse play-by-play and related data are generally distributed under the Creative Commons Attribution 4.0 International license. Attribute nflverse and review the license attached to each upstream dataset.
- FTN charting fields, when used, are distributed under Creative Commons Attribution-ShareAlike 4.0 and require additional FTN Data attribution. This project does not intentionally use those fields in its current feature schema.
- NFL team and player names and marks belong to their respective owners. This project is independent and is not endorsed by the NFL.

Loader documentation: https://github.com/nflverse/nflreadpy
